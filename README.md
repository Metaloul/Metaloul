## Ce que je fais

- **Régie et direct** : une suite d'applications de régie (intercom, lecture, contrôle) écrites en Rust avec Tauri, pilotables depuis un Stream Deck via Bitfocus Companion.
- **Web** : sites vitrines et applications web, d'Astro à Next.js, avec CMS quand le client doit pouvoir éditer lui-même.
- **Outils et domotique** : utilitaires en Rust et en Go, intégrations matérielles (synchronisation Philips Hue sur téléviseurs LG webOS, par exemple).
- **Jeu vidéo** : un jeu d'horreur au rendu PS1 sous Godot 4, et quelques mods.

## Comment je travaille

- La logique dans un langage typé et testé, l'interface au-dessus.
- Des applications qui tournent sur Windows, macOS et Linux.
- Du code documenté, versionné, livré avec un changelog.
